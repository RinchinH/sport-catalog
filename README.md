# СпортКаталог

Учебный проект. Первый этап: FR-0 и FR-1.

## Запуск

Необходимо установить Docker Desktop и запустить его.

В корне проекта выполнить:

```powershell
docker compose up -d
```

Сайт: http://localhost:8080

Документация API: http://localhost:8080/api/docs

Проверка контейнеров:

```powershell
docker compose ps
```

## Сценарий проверки

1. Зарегистрировать нового пользователя.
2. Войти с его логином и паролем.
3. Убедиться, что открывается личный кабинет.
4. Обновить страницу и проверить сохранение входа.
5. Выйти и попробовать войти с неверным паролем.
6. Попробовать создать пользователя с занятым логином.
7. Проверить, что GET /api/auth/me без JWT возвращает 401.
